# InfBlog - 个人博客框架

一个可供参考的开源个人网站及源码，包含**博客书写、音乐播放器、资源分享、网页藏品**等多个组件，
面向想搭建个人网站的开发者。

**在线演示**：<7日内上线>

---

## 技术栈

| 层级 | 选型 |
|------|------|
| 框架 | Next.js 16 (App Router) + TypeScript |
| 样式 | Tailwind CSS v4 + Motion |
| 组件库 | shadcn/ui（基础）+ MagicUI / Aceternity UI（装饰） |
| 3D | three.js + @react-three/fiber + @react-three/drei |
| 认证 | Auth.js (next-auth v5) + bcryptjs |
| ORM / 数据库 | Prisma + SQLite |
| 内容 | MDX（文章/动态）、react-markdown 预览 |
| 其他 | Zustand、cmdk、fuse.js、shiki、Sonner、next-themes |
